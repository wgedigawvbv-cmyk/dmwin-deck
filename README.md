# デュエマ デッキ工房

デュエル・マスターズ（オリジナル環境）のデッキを組んで、**一人回し**でデータを取るツールです。
ブラウザの中だけで動きます。サーバーに何も送りません。

→ **（ここに公開したURLを貼る）**

## できること

**デッキを組む**
実装済みの **970枚** から40枚を選びます。文明・コスト・種族・効果の言葉で絞り込めます。
マナカーブ、文明の配分、役割（加速・ドロー・除去・ブロッカー・受け・攻め・妨害・決め札・盾）の
充足がその場で出ます。大会の入賞リスト48個をお手本として読み込めます。

**ゴールを決める**
一人回しは既定で「相手の盾を割り切るまでのターン数」を測りますが、
デッキの目的がそれでないなら、その数字は意味を持ちません。
そこで**目的を部品に分けて書き、どこをゴールと呼ぶかを自分で決められます**。
部品ごとに「何割の対戦で・何ターン目にそろったか」「どこで止まったか」が出るので、
**何が足りなくて崩れたのか**が分かります。

**回す**
相手が何もしない壁を相手に、数百〜数千戦を回します。
殴り切りターンの分布、3ターン事故率、札ごとの使用率・腐り率・マナ行き率、
ゴールの部品ごとの到達率が出ます。

**共有する**
組んだデッキとゴールをURLに入れて渡せます。サーバーには何も保存されません。

## 使い方

ページを開くだけです。スマホでも動きます（下にタブが出ます）。

はじめて「回す」を押した時だけ、ブラウザがPython本体（Pyodide）を読み込むので十数秒かかります。
2回目からはすぐ始まります。PCで直接動かすより2〜4倍遅いので、まずは300戦で様子を見てください。

デッキとゴールはこの端末の中に覚えておきます（サーバーには送りません）。
持ち出すときは「書き出し」のテキストを使ってください。

## 手元で動かす

```
git clone https://github.com/<ユーザー名>/dmwin-deck.git
cd dmwin-deck
npm install pyodide@0.29.5 --no-save
python webbuild.py --pyodide node_modules/pyodide
python -m http.server 8080 --directory web
```

→ http://localhost:8080/

※ `index.html` をダブルクリックして `file://` で開いても動きません（Web Worker が使えないため）。

PCで直接回すほうが速いです。

```
python deckui.py                 # デッキを組む画面を作る
python solo.py --deck-file mydeck.txt --games 3000 --pilot plan
python serve.py                  # 同じWi-Fiのスマホから使う
```

## カードの実装について

970枚のうち **810枚は書かれている効果を全部**、**82枚は一部を省いています**。
省いた点はカード1枚ずつに自分の言葉で書いてあり、画面でカードを選ぶと読めます。
カードの文は公式テキストの写しではなく、**自分の言葉で書き直したもの**です。

効果の中の選択（除去の対象、捨てる札、踏み倒す札）は、デッキごとの作戦ではなく
**全カード共通の決まり**で機械的に決めています。「このデッキはこう回す」という手順は
一行も書いていません。デッキの強さと操縦の上手さを混ぜないためです。

## 入賞リストについて

お手本のデッキは公式カバレージと公開記事から書き取ったものです。
**使用者の名前・ハンドルは載せていません。**
情報自体は公開されていますが、個人のサイトで「この人はこのデッキを使った」という形で
載せ直す必要はないと考えたためです。大会・順位・デッキの型は残してあります。
